CAT HUB — Netlify Static Website

Includes:
- CAT HUB cat logo with subtle sitting/breathing animation
- 5-second RGB loading screen
- RGB dashboard accents and borders
- Animated ambient glow and hero section
- Six script listings with copy buttons
- Local-browser copy and like counters
- Search and Discord link
- Mobile-friendly layout

Deploy by extracting the ZIP and uploading index.html plus the assets folder to Netlify. Keep index.html at the site root.

Note: the sitting animation is a gentle CSS breathing/bobbing effect applied to the supplied logo image; it does not separately animate the cat's tail or limbs. Counters are local to each browser.
